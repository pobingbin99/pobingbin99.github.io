Rabbit Habit

  • PWA
  • Habit Tracker
  • Team Project

팀 채팅과 실시간 알림으로 습관 형성을 돕는 개인·팀 습관 관리 서비스입니다. 픽셀 토끼의 상태와 성장 시스템을 통해 습관 실천에 재미와 동기를 더하고, 개인 습관뿐만 아니라 팀원들과 함께 목표를 공유하고 실천할 수 있도록 구성했습니다.

역할

Full-Stack

담당 영역

로그인, 메인 화면, DB 연동, 배포

주요 구현

  • NextAuth.js 기반 인증 흐름을 구현하고, 카카오 OAuth를 연동해 로그인 기능 구현
  • PixiJS를 활용해 토끼의 상태와 움직임을 표현하는 인터랙티브 픽셀 메인 화면 구현
  • Prisma ORM으로 PostgreSQL 데이터베이스를 연동하고, 스키마 및 데이터 관계를 관리
  • Supabase Storage를 활용해 프로필 이미지 등의 이미지 업로드 및 저장 기능 구현
  • Vercel을 활용해 Next.js 애플리케이션을 배포하고 운영 환경 구성

기술 스택

  • TypeScript
  • NextAuth.js
  • Prisma
  • PostgreSQL
  • Supabase
  • PixiJS

Peek&Pick

  • Barcode
  • AI Shopping
  • Team Project

한국 편의점을 이용하는 외국인을 위한 바코드 기반 AI 쇼핑 지원 서비스입니다. 상품 바코드를 스캔하면 상품 정보와 리뷰를 다국어로 제공하며, AI 리뷰 요약·상품 추천·챗봇 기능을 통해 상품 선택을 돕습니다. 주변 편의점 길 안내 기능까지 제공해 낯선 환경에서도 편리하게 이용할 수 있도록 구성했습니다.

역할

Full-Stack

담당 영역

리뷰, 다국어, 메인 화면, 배포

주요 구현

  • 리뷰 작성·조회·수정·삭제 기능과 관련 화면 및 API 구현
  • 다중 이미지 업로드와 썸네일 생성 기능을 구현해 리뷰 이미지 관리
  • useInfiniteQuery와 IntersectionObserver를 활용해 리뷰 무한 스크롤 구현
  • react-i18next를 활용한 한국어·영어·일본어 3개 언어 지원
  • Spring AI를 활용한 사용자 국적 기반 리뷰 번역 기능 구현
  • AWS 기반 배포 환경 구성: 프론트엔드 S3·CloudFront, 백엔드 EC2·Docker·Nginx

기술 스택

CarTalk

  • AI
  • RAG Chatbot
  • Capstone

중고차에 대한 지식이 부족한 사용자도 원하는 차량 정보를 쉽게 찾을 수 있도록 돕는 AI 챗봇 서비스입니다. 사용자의 조건을 바탕으로 중고차 매물과 관련 정보를 검색하고, RAG를 통해 필요한 정보를 답변으로 제공합니다.

역할

Frontend, RAG 설계

담당 영역

UI 설계, 데이터 수집, RAG 파이프라인

주요 구현

  • 챗봇 웹페이지 UI 설계 및 React를 활용한 프론트엔드 구현
  • 중고차 관련 외부 데이터를 수집하고 검색에 활용할 수 있도록 정리
  • 중고차 매물 및 관련 정보를 기반으로 RAG 지식 베이스 구축
  • LangChain을 활용해 검색 결과와 LLM 답변을 연결하는 RAG 파이프라인 구현

기술 스택

  • TypeScript
  • Tailwind CSS
  • Python
  • LangChain
  • RAG
